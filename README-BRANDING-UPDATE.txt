TOEFL 2026 — LOGO + FAVICON UPDATE
==================================

This is a drop-in project update.

REPLACE / ADD THESE FILES IN THE ROOT OF YOUR EXISTING TOEFL PROJECT:
- index.html
- task-explorer.html
- practice-packs.html
- writing-practice.html
- speaking-practice.html
- branding.css
- toefl-2026-master-guide-logo.webp
- toefl-2026-logo-header.webp
- toefl-2026-favicon.webp
- toefl-2026-favicon-512.png
- favicon.ico

WHAT CHANGED
- New TOEFL 2026 logo is now used in site navigation/branding.
- Old T26 visual mark is replaced through a small branding override layer.
- Task Explorer and practice pages use the new logo directly.
- favicon.ico + WebP favicon are linked on every updated HTML page.
- Apple touch icon is included.
- Existing application logic, practice data, interactions, and original CSS/JS remain untouched.

INSTALL
Unzip this package directly over the root folder of the current TOEFL project
and allow the matching HTML files to be replaced.
